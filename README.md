# Sales Data Analysis – Python & Power BI

Projeto de análise de dados de vendas, combinando exploração em Python e construção de dashboard executivo no Power BI.

## Objetivo
Analisar a performance comercial, identificar padrões de receita e lucro, avaliar impacto de descontos e gerar insights estratégicos para suporte à tomada de decisão.

## Etapas do Projeto

### 1️ Análise em Python
- Tratamento e limpeza de dados com pandas
- Análise temporal de vendas
- Identificação de produtos e categorias mais vendidos
- Análise de faturamento
- Avaliação de receita, lucro e margem
- Visualizações exploratórias com matplotlib/seaborn

### 2️ Dashboard Executivo
O dashboard foi estruturado com foco executivo e storytelling analítico, incluindo:
- Receita total
- Lucro Total
- Margem %
- Crescimento mensal
- Tendência mensal de Receita e Lucro
- Região mais lucrativa
- Categoria mais lucrativa
- Impacto do desconto na margem
- Top 5 subcategorias por lucro
- Análise por segmento de cliente

## Tecnologias
- Python (pandas, matplotlib, seaborn)
- Power BI
- DAX
- Modelagem de dados

## Resultados
Principais Insights Gerados
- Identificação das categorias mais rentáveis
- Avaliação do impacto de descontos na margem
- Análise de sazonalidade nas vendas
- Comparação de performance por região e segmento
- Identificação de subcategorias com maior potencial de lucro
